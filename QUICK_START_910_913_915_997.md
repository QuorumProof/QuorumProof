## 🚀 Getting Started (5 minutes)

### 1. Build All Contracts
```bash
cd /workspaces/QuorumProof

cargo build --release --target wasm32-unknown-unknown -p quorum_proof
cargo build --release --target wasm32-unknown-unknown -p sbt_registry
cargo build --release --target wasm32-unknown-unknown -p zk_verifier
```

### 2. Run Tests
```bash
# All tests
cargo test --workspace

# Specific feature tests
cargo test test_veto
cargo test test_atomic
cargo test test_migration

# API tests
cd api-server && npm test
```

### 3. Verify Compilation
```bash
cargo check --all --all-targets --all-features
echo "✅ Compilation successful!"
```

## 🔧 Key Functions

### #910: Veto Management
```rust
// Initialize
client.init_veto_authorities(&admin, &authorities)

// Request veto for an attestation
let veto_id = client.request_veto(
    &veto_authority,
    &credential_id,
    &slice_id,
    &attestor,
    &None,  // optional reason
    &None   // optional evidence hash
);

// Execute after time-lock expires
let ready = client.execute_veto(&executor, &veto_id); // true if executed

// Query
client.get_veto_request(&veto_id)
client.get_credential_veto_requests(&credential_id)
client.get_veto_audit_log()
```

### #913: Atomic Operations
```rust
// Initialize
client.init_atomic_operations(&admin)

// Begin transaction
let txn_id = client.begin_atomic_transaction(
    &initiator,
    &1u32,        // operation_type
    &op_data,
    &3600u64      // timeout_seconds
);

// Advance through phases
client.advance_atomic_phase(&admin, &txn_id, &1u32, &None);  // Phase 1
client.record_atomic_phase_result(&admin, &txn_id, &1u32, &true, &None, &None);

client.advance_atomic_phase(&admin, &txn_id, &2u32, &None);  // Phase 2
client.record_atomic_phase_result(&admin, &txn_id, &2u32, &true, &None, &None);

client.advance_atomic_phase(&admin, &txn_id, &3u32, &None);  // Phase 3
client.record_atomic_phase_result(&admin, &txn_id, &3u32, &true, &None, &None);

// Commit or rollback
client.commit_atomic_transaction(&admin, &txn_id);
// OR
client.initiate_atomic_rollback(&admin, &txn_id, &None);
```

### #915: Migration
```rust
// Initialize
client.init_migration_v2(&admin)

// Start migration V1→V2
let job_id = client.start_migration_v1_to_v2(&admin);

// Migrate in chunks
loop {
    let checkpoint = client.migrate_chunk_v1_to_v2(&admin, &100u32);  // chunk_size=100
    if checkpoint.status.as_u32() == 3 { break; }  // Completed
    std::thread::sleep(Duration::from_secs(1));
}

// Verify
assert!(client.validate_migration_integrity());

// Or pause/resume/rollback
client.pause_migration(&admin);
client.resume_migration(&admin);
client.rollback_migration(&admin);
```

## 🚨 Common Issues & Fixes

### Issue: Compile errors in new modules
**Fix**: Ensure all imports are correct and dependencies updated
```bash
cargo update
cargo clean
cargo build --release --target wasm32-unknown-unknown -p quorum_proof
```

### Issue: Tests failing
**Fix**: Run with verbose output to see actual errors
```bash
cargo test --lib -- --nocapture
```

### Issue: API not starting
**Fix**: Check soroban environment variables are set
```bash
export STELLAR_NETWORK=testnet
export STELLAR_RPC_URL=https://soroban-testnet.stellar.org
export CONTRACT_QUORUM_PROOF=<contract-id>
npm start
```
